# Connect 4

## Опис проєкту

**Connect 4** — це стратегічна гра для двох гравців, у якій людина грає проти штучного інтелекту (ШІ). Мета гри — першою зібрати чотири свої фішки поспіль по горизонталі, вертикалі або діагоналі.

ШІ використовує алгоритм **Minimax з Alpha-Beta Pruning**, щоб аналізувати можливі ходи та обирати найкращий варіант.

## Технології

- Python
- Minimax
- Alpha-Beta Pruning
- Стандартна бібліотека Python

## Правила гри

- На початку гри поле порожнє.
- Людина ходить першою.
- Ігрове поле складається із **7 колонок і 6 рядків**.
- Гравець обирає колонку від 1 до 7.
- Фішка падає на найнижчу вільну позицію у вибраній колонці.
- Після ходу людини ШІ аналізує поточний стан поля та обирає свій хід.
- Гра триває, поки один із гравців не збере чотири фішки поспіль або всі клітинки не будуть заповнені.

### Умови перемоги

Перемогти можна, зібравши чотири фішки поспіль:

- По горизонталі.
- По вертикалі.
- По діагоналі в напрямку ↘.
- По діагоналі в напрямку ↗.

Якщо поле заповнене, але ніхто не зібрав чотири фішки поспіль, оголошується нічия.

## Алгоритм штучного інтелекту

### Minimax

Minimax — це алгоритм, який будує дерево можливих ходів і оцінює результати, щоб обрати найвигідніший хід для ШІ.

- **MAX** — ШІ, який намагається максимізувати свій результат.
- **MIN** — людина, ходи якої оцінюються як спроби мінімізувати результат ШІ.
- **Глибина пошуку** — 4–5 ходів.

Алгоритм враховує, що людина також намагатиметься обирати найвигідніші для себе ходи.

### Alpha-Beta Pruning

Alpha-Beta Pruning — це оптимізація Minimax, яка дозволяє не аналізувати гілки дерева рішень, що не можуть покращити вже знайдений результат.

- **Alpha** — найкращий результат, який MAX уже знайшов.
- **Beta** — найкращий результат, який MIN уже знайшов.
- Якщо `alpha >= beta`, подальший аналіз відповідної гілки можна припинити.

Це зменшує кількість варіантів, які ШІ повинен перевірити.

## Оцінювання позицій

ШІ оцінює групи з чотирьох клітинок, щоб визначити, які ходи є вигідними.

| Ігрова ситуація | Оцінка |
|---|---:|
| ШІ переміг | +10000 |
| ШІ має три фішки поспіль | +100 |
| ШІ має дві фішки поспіль | +10 |
| Нейтральна позиція | 0 |
| Людина має дві фішки поспіль | -10 |
| Людина має три фішки поспіль | -100 |
| Людина перемогла | -10000 |

Додатні значення вказують на вигідні позиції для ШІ, а від’ємні — на вигідні позиції для людини.

## Симуляція ходів ШІ

Під час аналізу можливих ходів ШІ не повинен змінювати справжнє ігрове поле. Для цього створюється копія поля, у якій симулюються можливі ходи.

```python
new_board = copy.deepcopy(board)
```

Це дозволяє аналізувати різні варіанти розвитку гри, не змінюючи поточного стану дошки.

## Основний процес гри

1. Створення порожнього ігрового поля.
2. Вибір колонки людиною.
3. Розміщення фішки людини.
4. Перевірка перемоги людини.
5. Аналіз поля та вибір ходу ШІ.
6. Розміщення фішки ШІ.
7. Перевірка перемоги ШІ або нічиєї.
8. Повторення циклу до завершення гри.
